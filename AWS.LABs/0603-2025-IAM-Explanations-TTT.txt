ROLE
- similar to a user (identity with permissions)
- does NOT have credentials (password or keys)
- assumable, temporarily by anyone / anything who needs it

ROLE prevents the need to hard code credentials into an application
- e.g. create an EC2 instance assign it a role
- an IAM role automatically deploys AWS credentials to the resources [that assume it]
- configure instance [assign role]

  POLICY
  - JSON : effect : action : resourc (ARN) : condition 
  - Allows IAM users to rotate their own credentials programmatically and in console.
  - Allow Lambda function access to dynamo db
  - Allow users start / stop EC2 instance
  - To take effect attach the policy to one of your identities [USER, GROUP, ROLE]

IAM

- find policy e.g. Administrator access
- can search and add multiple policies same screen
- [JSON] view - shows JSON document that provides access
- [SUMMARY] shows various permission by entity
