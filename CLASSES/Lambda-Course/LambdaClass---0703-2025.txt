Common Usage
- module.exports.updateTodo=(event,context,callback) 

-event-
In AWS Lambda, the event object represents the input to your Lambda function. 
It's automatically passed in by AWS when the Lambda function is invoked. 
Its structure varies depending on how your Lambda is triggered.

-context-
In AWS Lambda, the context object contains runtime information about the Lambda function execution. 
AWS automatically provides it when your function is invoked.
You rarely need to use it for basic tasks, but it becomes helpful for advanced scenarios like logging, timeouts, or function metadata.

-callback-
In AWS Lambda (specifically in Node.js), 
the callback is a function provided by the Lambda runtime 
that you call to signal that your function is done—whether it succeeded or failed.
