# Welcome to the AI Developer Bootcamp

Before writing any code, make sure all the required libraries are installed.

A `requirements.txt` file is included at the root of this course with all the Python packages you need.

**PyCharm should install them automatically** when you open the course. If you see a notification asking to install packages, click **Install**.

If the automatic install did not happen, open the terminal in PyCharm (**View | Tool Windows | Terminal**) and run:

```
pip install -r requirements.txt
```

Once the packages are installed, click **Next Task** to begin.
